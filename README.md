# Анализ бизнес-показателей: LTV, CAC, ROI

## О проекте
В проекте исследуется эффективность привлечения пользователей и окупаемость маркетинговых затрат.  
Цель — понять, какие каналы привлечения работают лучше, как ведут себя пользователи и насколько окупаются инвестиции.

## Задачи
- рассчитать ключевые маркетинговые и продуктовые метрики
- провести когортный анализ
- оценить LTV, CAC и ROI
- сравнить каналы привлечения
- сформулировать выводы и рекомендации для бизнеса

## Использованные инструменты
- Python
- pandas
- NumPy
- matplotlib
- Jupyter Notebook

## Ключевые этапы работы
1. Предобработка данных  
2. Исследовательский анализ данных  
3. Расчёт метрик привлечения и удержания  
4. Когортный анализ  
5. Интерпретация результатов и выводы

## Результат
В результате проекта были выявлены различия между каналами привлечения по стоимости, окупаемости и качеству пользователей.  
Сформулированы выводы о том, какие источники трафика выглядят более эффективными, а какие требуют пересмотра.
